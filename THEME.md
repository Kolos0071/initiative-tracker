# Система тем

## Обзор

В проекте реализована система темной и светлой темы без хардкода цветов. Все цвета управляются через CSS-переменные.

## Структура

### CSS-переменные (`src/renderer/src/assets/main.css`)

Все цвета определены в виде CSS-переменных:

**Основные переменные:**
- `--color-primary` — основной акцентный цвет
- `--color-background` — цвет фона страницы
- `--color-surface` — цвет поверхностей (карточек, панелей)
- `--color-text` — основной цвет текста
- `--color-text-secondary` — вторичный цвет текста
- `--color-border` — цвет границ
- `--color-button-bg` — фон кнопок
- `--color-success` — цвет успеха (зеленый)
- `--color-warning` — цвет предупреждения (оранжевый)
- `--color-danger` — цвет ошибки/опасности (красный)

**Специфичные переменные:**
- `--color-header-bg` — фон заголовка
- `--color-card-bg` — фон карточек
- `--color-log-bg` — фон лога боя
- `--color-target-bg` — фон выбранной цели
- `--color-attack-button-bg` — фон кнопки атаки
- и другие...

### Переключение темы (`src/renderer/src/components/ThemeToggle.vue`)

Компонент переключателя темы:
- Кнопка с иконкой ☀️/🌙
- Сохраняет выбор в `localStorage`
- Учитывает системные предпочтения
- Автоматически применяет тему при загрузке

## Как использовать

### В HTML/Vue шаблонах

```vue
<template>
  <!-- Просто используйте виджет переключателя -->
  <ThemeToggle />
</template>
```

### В CSS

```css
/* Вместо хардкода цветов */
.my-element {
  background-color: #1a1a1a;  /* ❌ Плохо */
  color: #ffffff;             /* ❌ Плохо */
}

/* Используйте переменные */
.my-element {
  background-color: var(--color-surface);  /* ✅ Хорошо */
  color: var(--color-text);                /* ✅ Хорошо */
}
```

### Добавление новой темы

Чтобы добавить новую тему, просто добавьте новый блок в `main.css`:

```css
[data-theme="custom"] {
  --color-primary: #YOUR_COLOR;
  --color-background: #YOUR_COLOR;
  /* ... и так далее */
}
```

## Как работает

1. По умолчанию применяется светлая тема (класс `:root`)
2. При переключении на темную тему, на `<html>` устанавливается атрибут `data-theme="dark"`
3. CSS автоматически применяет переменные из блока `[data-theme="dark"]`
4. Выбор сохраняется в `localStorage` и восстанавливается при перезагрузке

## Преимущества

✅ **Никакого хардкода** — все цвета в одном месте  
✅ **Легкое изменение** — изменил переменную — изменилось везде  
✅ **Поддержка системной темы** — автоматически следует настройкам ОС  
✅ **Сохранение выбора** — пользователь не теряет выбор темы  
✅ **Доступность** — используются семантические цвета (success, warning, danger)

## Цветовые схемы

### Светлая тема
- Фон: светло-серый (#f5f5f5)
- Текст: темно-серый (#1a1a1a)
- Поверхности: белый (#ffffff)

### Темная тема
- Фон: темно-серый (#242424)
- Текст: светло-серый (rgba(255, 255, 255, 0.87))
- Поверхности: темно-серый (#1a1a1a)
